# 이스라엘 왕조 연대표

Notion에서 사건을 수정하고, GitHub Pages에서 최종 그래프를 확인합니다.

- 위: 과거 / 아래: 미래. 연도 차이와 세로 거리가 비례합니다. 연도 0은 사용하지 않습니다.
- 열 순서: 주요 사건 → 통일왕국 · 남유다 → 북이스라엘 → 선지자 → 주변 국가.
- 공개 필드: 이름·사건, 분류, 시작·종료 연도, 연도 불확실, 이름 굵게. **메모·페이지 내용·인증정보는 공개하지 않습니다.**
- 초기 데이터는 제공된 원본의 86항목이며, 연도 미정 2개는 목록에만 표시합니다. 역사적 연대는 재검증하지 않았습니다.

## 최초 연결

1. GitHub Pages의 Source를 **GitHub Actions**로 선택합니다.
2. Notion에서 내부 연결을 만듭니다. **Read content만 허용**하고 사용자 정보·쓰기·댓글 권한은 끕니다.
3. 대상 `연대표 사건` 데이터베이스의 ••• → 연결 추가에서 해당 연결을 선택합니다. 다른 비공개 페이지는 공유하지 마세요.
4. 저장소 Settings → Secrets and variables → Actions에 **NOTION_TOKEN**이라는 repository secret을 등록합니다. 토큰을 코드·이슈·채팅에 적지 마세요.
5. 다음 예약 작업 또는 Actions의 Run workflow로 연결을 확인합니다. 최초 성공 이후 화면의 ‘초기 데이터’ 안내가 사라집니다.

## 갱신

Actions가 약 10분마다 필요한 공개 필드만 읽습니다. 정렬 순서와 조회 시간은 제외하고 실제 데이터를 비교하며, 변경된 경우에만 JSON을 커밋하고 Pages를 배포합니다. 페이지가 열린 동안에는 1분마다 게시된 JSON을 확인합니다. 새로고침 버튼은 게시된 최신 결과를 다시 읽으며 GitHub 작업을 직접 시작하지 않습니다.

예약 실행은 정확한 시간 보장이 없고 지연될 수 있습니다. GitHub는 공개 저장소가 60일간 활동이 없으면 예약 작업을 중지할 수 있으므로, 장기간 수정하지 않았다면 Actions에서 다시 활성화해야 할 수 있습니다. 이 구조는 영구적인 무관리 실시간 서비스가 아닙니다.

Notion 조회·검증 실패 시 기존 공개 데이터를 유지하고 배포를 중단합니다. 속성명을 임의로 변경하거나 분류를 새로 만들면 연결 코드의 매핑 수정이 필요합니다. 최대 2,000개 항목과 연도 -9999~9999를 지원하며, 그림이 너무 길면 화면에서 1년 높이를 낮춰 주세요.

초기 공개 JSON은 token 없이도 게시되지만 **NOTION_TOKEN을 설정하기 전에는 Notion 변경이 반영되지 않습니다.**

## 무료 사용 범위

공개 저장소와 표준 GitHub 호스팅 러너를 사용합니다. GitHub Pages·Actions의 사용량·정책 제한이 적용됩니다. 별도 도메인이나 유료 서비스는 설정하지 않습니다.
